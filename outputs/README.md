# Outputs

Everything under this folder is generated by the pipeline. Never edit by hand.

- `dashboard/executive-retention-command-center.html` — the interactive
  deliverable. Self-contained: embedded data and chart runtime, no server or
  network needed. Regenerate with `make dashboard`.
- `graphs/` — the static chart pack (18 PNGs). Regenerate with `make charts`.
- `reports/churn-retention-intelligence-report.pdf` — the narrative analytical
  report (~30 pages, charts inline). Regenerate with `make report`.

The three published folders above are tracked so GitHub Pages can serve them.
The working intermediates `tables/` (analytical tables and governance check
logs) and `profiling/` are `.gitignore`d and never appear in the public tree.
Rebuild everything with `make release`.

Live dashboard: <https://mfidalgomartins.github.io/churn-retention-intelligence/>

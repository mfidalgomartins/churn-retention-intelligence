# Outputs

Everything under this folder is generated by the pipeline — never edit by hand.

- `dashboard/executive-retention-command-center.html` — the deliverable
- `tables/` — analytical tables and governance check logs

`outputs/tables/` is `.gitignore`d; the dashboard HTML is tracked so GitHub Pages
can serve it. Regenerate with `make all`.

# Documentation

- `decision_memo.md` — one-page executive read-out.
- `release_spec.md` — current release scope and acceptance criteria.
- `methodology/`
  - `feature_dictionary.md` — every column in `customer_retention_features.csv`. Generated by `make features`.
  - `risk_scoring_methodology.md` — scoring math and tier rules. Generated by `make risk`.
  - `synthetic_data_generation_note.md` — what the simulator assumes.
- `architecture/dashboard_design_note.md` — why the dashboard is shaped the way it is.
- `governance/`
  - `qa_release_framework.md` — readiness states and gate logic.
  - `release_runbook.md` — how to cut a release.

Files marked **generated** are regenerated whenever the corresponding `make`
target runs — edit the source code, not the file.

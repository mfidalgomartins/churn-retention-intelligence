  calibration, metrics, and monitoring.

  payback, and LTV definitions.
- `methodology/experimentation.md` — assignment, holdout, estimand,
  uncertainty, and saved-MRR identity.
- `methodology/synthetic_data_generation_note.md` — simulator assumptions and limitations.

- `governance/production_operations.md` — source adapters, scheduling,

the generating module rather than editing a generated output.
